# 酒米の系図

酒米の品種を探すと、その品種の親（母・父）と子が並び、名前をたどって祖先や子孫へ移れるページです。育成した県と年、作っている県と量（令和7年産）も出ます。

- 地図：品種を選ぶと作っている県が量に応じて濃く塗られます。県を押すとその県の品種が並びます。全国の順位もここで見られます
- 一族：選んだ品種の祖先と子孫を1枚で見られます
- 全体：ひとつにつながる461品種の木を1枚に描いています（箱の色は育成した地方）。品種を押すとその祖先と子孫が浮かび上がります

見る: https://y-kanno-sakenote.github.io/sakamai-keizu/

- 親の情報がどちらとも決められない品種（資料によって親が違うもの）は、どちらかに寄せず並べています
- 本の系譜図・本文は転載していません。品種ごとに出典の頁を示しています

出典
- 主な出典：副島顕子『酒米ハンドブック 改訂版』文一総合出版、2017
- 数量：「米穀の農産物検査結果」醸造用玄米（令和7年産速報値・令和8年3月31日現在）（農林水産省）https://www.maff.go.jp/j/seisan/syoryu/kensa/kome/ （2026年10月27日に利用）を加工して作成
- 親の情報は、農研機構イネ品種データベースと各県の試験場の報告などで照合しました
